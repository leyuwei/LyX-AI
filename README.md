## 从选区到修改稿，留在写作流程里

在 LyX 正文中框选文字，右键打开助手。程序自动获取前后正文，你可以检查上下文、选择提示词和模型，再阅读建议，将确认后的修改应用到 LyX 当前选区或光标位置。

**框选正文 → 自动补充上下文 → 问询 AI → 预览文字与公式 → 应用修改**

| 亮点 | 带来的便利 |
|---|---|
| **自动理解正文上下文** | 读取当前文档，包括未保存的编辑；按可选范围提取前后文，排除跨正文范围中的 Note、Footnote 等对象。 |
| **清爽的正文入口** | 白色界面保持清晰；原文、前文、后文只显示三个带字符数的按钮，需要时打开弹窗查看和编辑。 |
| **公式原生写回** | 行内、Displayed、align/aligned 等公式成为可继续编辑的 LyX 数学对象，保留支持的编号与标签结构。 |
| **Markdown 与公式阅读** | 标题、列表、表格与数学公式在离线预览中排版显示，便于核对建议与修改稿。 |
| **模型与中转站自由配置** | 多配置档管理地址、协议、密钥、模型、生成参数、思考深度、代理和超时。 |
| **设置自动记忆** | 回复语言、模板选择与编辑、模型、前后文范围、窗口布局自动保存；支持前后各 1200 字符。 |
| **本地问答历史** | 按问答轮次单独查看 AI 回复，问题与思考摘要分开展示；可搜索、载入后继续追问，失败或取消保留部分回复。 |
| **小屏幕友好** | 窗口按屏幕适配，输入与输出可滚动，底栏保持单行；预览切换保留窗口和页面位置。 |
| **可定制的写作任务** | 学术润色、语法校对、精简、逻辑检查、公式整理和中英翻译等模板可编辑、另存；支持继续追问。 |
| **可检查、可撤销的应用过程** | 发送前查看实际请求；应用时自由选择当前选区或光标；替换或插入后可在 LyX 一次撤销。 |

## 连接你自己的模型

![独立模型配置窗口：服务商配置档、接口协议、思考深度与超时设置](docs/images/models-zh.png)

*配置界面演示，地址和模型为占位示例，不含密钥。*

提供 OpenAI、Claude、DeepSeek、Kimi、Grok、GLM / BigModel、BigModel Coding、Z.ai 和自定义中转的配置入口。支持 **OpenAI Chat Completions、OpenAI Responses、Claude Messages**，可按服务商或中转站实际提供的协议选择。

同一家服务可分别保存官方接口和中转配置。生成参数、思考模式与深度、输出上限、自定义请求头和高级 JSON 均可配置；具体可用参数与模型权限由接口服务决定。

## 文字与公式一起修改

助手把可应用的修改稿放进独立的“待替换正文”编辑区。你可以继续编辑和预览，再通过窗口底部始终可见的 **应用到 LyX 当前位置** 按钮写回。

- 支持行内公式、单行 Displayed 和多行对齐公式，识别裸露的 `align`、`aligned` 等环境。
- 保留 Theorem、Lemma 等目标布局；LaTeX 定理环境及文本格式交由 LyX 原生导入。ERT 源码区域保留真正的 LaTeX 命令，供文档排版使用。
- 点击“问询原文 / 前文 / 后文”按钮，在弹窗查看和编辑，保存后用于下次问询；前后文供模型理解，修改目标明确。
- `\eqref{…}`、`\ref{…}`、`\cite{…}` 等引用写成原生 LyX 对象，由文档解析编号和文献。
- 应用时读取最新位置：有选区就替换，无选区就在光标处插入。允许等待 AI 时调整选区或编辑同一文档；切换到其他文档时停止写入。覆盖选区内的 Note、Footnote 等对象也会被移除，可一次撤销恢复。
- 菜单跟随 LyX 界面语言，助手可切换中英文，并记住语言选择。

## 回看历史，继续问询

![可搜索和载入的本地问答历史](docs/images/history-zh.png)

*历史界面演示，使用示例内容，未调用 AI 接口。*

点击底部 **问答历史…**，默认单独显示 **AI 回复**，通过轮次下拉框查看各次问询及追问的答案。“用户问询”“思考 / 摘要”和“完整对话”分开查看，也可搜索更早的内容或加载更多记录。独立打开助手会恢复上次对话；从 LyX 框选新文字启动则开始新目标。设置与历史在覆盖升级后保留。

定理环境需要当前文档启用相应的 Theorems 模块；示例见 `examples/regions-demo.lyx`。未知自定义宏的显示取决于文档配置。

## 本地助手，发送范围可见

程序安装在用户目录，不改写 LyX 程序文件。凭据使用 **Windows DPAPI / macOS 钥匙串** 保护；已发送问询的原文、前后文、回答与思考摘要保存在本机 `history.sqlite3`；可通过“问答历史…”搜索、载入和删除，不自动上传。自动上下文使用短暂的本地文档快照，读取后删除。

预览使用随程序分发的 KaTeX 与字体，无需联网下载渲染资源。点击发送后，输入区中的正文和上下文提交给你配置的 API；可事先查看完整请求。

## 开始使用

**macOS 12 及以上：** 完整解压 macOS 安装包，退出 LyX 与助手，运行 `Install-macOS.command`。程序安装至 `~/Applications/LyXAI.app`；正常打开 LyX 后即可通过右键菜单使用，中英文菜单同时显示。撤销快捷键为 **⌘Z**。详见 [macOS 安装与构建](docs/INSTALL.macOS.md)。

**Windows：**

1. 将 Windows 安装包完整解压，保存文档并退出 LyX 和助手，运行 `Install.cmd`。
2. 从开始菜单 **LyX AI - Start LyX** 启动，在主正文框选文字并右键打开助手。
3. 在“模型配置…”中填写自己的接口和密钥，核对上下文与提示词后发送。
4. 预览并检查修改稿，再点击全局应用按钮；需要恢复时在 LyX 按 **Ctrl+Z**。

覆盖安装保留模型、模板和语言设置。完整依赖目录须与 EXE 一起保留。请先在文档副本上体验写回功能，并从主正文选取文本。

从源码运行：

```powershell
python -m pip install -r requirements.txt
python main.py --configure
```
