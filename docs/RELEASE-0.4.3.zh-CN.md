# LyX AI 0.4.3

- 支持多个 Theorem、Proof、Standard 等正文布局共同写回；纯文本段落对应时分别保留布局、初始样式及标题/标签。显式 LaTeX 环境支持增加、删除和重排段落。
- 请求自动保留混合目标的定理/证明边界及 ERT 命令；修正仅凭选区末端光标误判源码内部的问题。混排 latex/tex 围栏与更多 LaTeX 命令使用原生导入，公式和可识别的框等结构成为原生对象。
- 纯文本跨段写回保留空的选区边界，避免选区外证明段落变成定理；恢复布局和粘贴置于同一撤销组。
- 内置提示词从程序预设加载，不持久化改写内容。编辑立即创建用户自定义模板，后续修改只更新该项，可关闭重开、切回内置或另存命名。旧版本被改写的预设迁移为自定义项，当前选择和内容保留。
- 紫色提示词面板突出标题、模板、回答语言和编辑区，在深色系统配色下保持可读。

完全无结构的纯文本若改变混合目标的段落数，会按正文布局应用并明确提示；保留定理边界请使用 LaTeX 环境。LaTeX 导入若遇到方向无法确认的空段落边界，会要求选到末尾段落正文，避免改动未选文字；仍支持多个布局。未知宏与自定义布局依赖文档已有配置，宏定义和文件/执行类命令不自动写入。ERT 编辑框显示源码是 LyX 的正常行为，最终由文档排版执行。

提示词配置格式升级；首次保存旧格式会备份为 `config.before-template-migration.json`。覆盖安装保留模型凭据和历史；回退旧程序需恢复旧配置备份。详见[升级教程](UPGRADE.zh-CN.md)和[测试说明](TESTING.zh-CN.md)。本次交付为 Windows，未在 macOS 实机验收新增写回逻辑。
