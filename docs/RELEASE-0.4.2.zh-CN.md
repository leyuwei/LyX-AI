# LyX AI 0.4.2

- 修复 macOS 打开 Markdown / 公式预览标签时的原生渲染崩溃。Cocoa 窗口从创建时使用 Qt 自己的 RHI 渲染层，不再在创建原生窗口后手动更改其渲染类型。
- Windows 的窗口句柄兼容处理保留原有逻辑。
- 增加 macOS 原生 Cocoa 界面检查：覆盖首次打开预览、切换标签与语言、滚动位置、窗口句柄与位置、正文和历史弹窗、小屏幕及深色配色。打包版也可显式执行同一检查。

macOS 用户完整解压 0.4.2 包，在保存文档并退出 LyX 和助手后运行 `Install-macOS.command` 覆盖安装；设置与历史保留。
