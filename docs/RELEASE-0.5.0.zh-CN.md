# LyX AI 0.5.0

修复混合布局写回与结构信息丢失，重点覆盖用户提供的长篇 lemma/proof 和图表内容。

- IEEEtran 自带定理布局与显式 AMS 模块冲突会令 tex2lyx 退出。现在按类提供的模块处理转换参数和环境别名，在临时目录预检，再一次原生粘贴；不再通过 LyX 的 `paste latex` 触发模态转换错误。
- 选区与上下文保留 Float、Figure、Table、Caption、Box/Minibox、其他 inset 容器内的文字，以及公式、标签、引用和 LaTeX 源码。仅排除 Note、Footnote 和边注内容。
- 图片保留原生对象，并按剪贴板来源目录解析资源路径，避免写回后失联；自动上下文匹配不受图片路径重定位影响。
- 图表标题、简单表格单元格和盒内文字可编辑；结构匹配时保留表格行列设置、边框、盒子/浮动项参数与对应段落间距。Caption 与 Box 内部的 Plain Layout 可写入原生公式，避免被误当作源码框。
- 图片、复杂合并表格与无法可靠重建的原生对象使用 `\lyxaiobject{…}` 标记保留，同时给 AI 提供可读内容。复杂对象内部暂作只读参考。不得删除或编造标记；关键标签或资源缺失时在写入前提示，防止静默丢失。
- 所有内置提示词增加双语结构保护规则。用户自定义模板保持原样，实际请求仍追加保护规则；内置模板继续从程序加载，编辑后转为自定义模板。
- 等待 Windows/macOS 导出快照完整写入，避免收到导出确认后立即读取空文件或半写入文件；超时不重复发出导出命令。
- 原生片段保留空选区边界；反向框选、多个定理/证明与正文混排均纳入实际 LyX 回归，所有写回检查均验证一次撤销恢复完整原文。

已有配置与历史兼容，覆盖安装保留 API 凭据、界面偏好和自定义模板。请完整解压、退出 LyX 与助手，再运行新包的 `Install.cmd`，详见[覆盖升级教程](UPGRADE.zh-CN.md)。

Windows 验证见[测试记录](TESTING.zh-CN.md)。本次不调用真实 AI 账户，不改写用户工作文档；macOS 新增写回逻辑尚未实机验收。自定义类、宏及任意复杂 inset 组合不在已验证覆盖范围内。

补充：模块兼容性已按标准声明通用化，包括类级排除、双向互斥、传递依赖、依赖重排、默认/用户移除模块及循环检测。定理可用性不再依赖类名白名单，非定理与用户自定义模块也纳入真实转换验证。详见[模块兼容性说明](MODULE-COMPATIBILITY.zh-CN.md)。
