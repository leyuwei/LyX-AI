# LyX AI 0.4.0

- 常用设置自动持久化：回复语言、当前模型、模板选择及编辑、自动上下文开关和范围、窗口大小位置、分栏与标签；关闭时刷新尚未落盘的设置。模型配置继续用“保存/取消”提交参数。
- 增加前后各 1200 字符，保留原有范围及用户选择。
- 底部状态固定单行，溢出省略，悬停查看完整反馈。
- 小屏幕按可用区域恢复窗口，输入和输出可滚动，工具栏自动分行；中英文均已在 640×480、800×600、1024×600 验收。
- 修复第一次打开阅读预览触发 Windows 窗口句柄重建；浏览器、页面、滚动位置复用，语言切换也不重建窗口。
- 本地 SQLite 历史保存问询、追问、回答、思考摘要、修改稿、模型和完成状态；支持搜索、加载更多、载入、继续追问、单条删除。失败/取消保留部分输出，重开可恢复上次对话；当前模型偏好不会被自动恢复的历史覆盖。
- 回写保留 Theorem/Lemma 等当前布局；LaTeX 环境、章节与文本格式使用 LyX 原生导入，ERT 整块、源码内部与光标插入保持真正的 LaTeX 源码。公式仍支持行内、Displayed 和 align/aligned。

定理环境需当前文档启用匹配的 Theorems 模块；文档自定义宏与布局按原配置解析。ERT 编辑框继续显示源码，最终由 LaTeX 排版。纯源码选区不猜测正文上下文；可手动补充。不支持自动写入文件读取、外部链接、宏定义或执行类命令。历史不会恢复失效的原生 LyX 选区作为回写目标。

历史文件位于配置目录的 `history.sqlite3`，是本地持久化内容，不含 API 认证字段，不自动上传。覆盖安装保留配置与历史；备份整个配置目录可一并备份。升级前未保存的旧会话无法恢复。

Windows 验证：94 项快速回归，90 项通过、4 项 macOS 专用检查跳过；真实 Windows 浏览器和窗口检查通过；真实 LyX 的新选区替换、光标插入、定理/引理/LaTeX/ERT 回写及一次撤销通过；导出的定理与源码公式已编译为 PDF。打包版另检验离线预览、界面、IPC、隔离菜单安装卸载与 ZIP 完整性。本次未在 macOS 实机打包验收。
