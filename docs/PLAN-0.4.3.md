# 0.4.3 实施与验收计划

1. 写回：移除单一正文布局限制。纯文本段落一一对应时逐段保留布局和初始样式；显式 LaTeX 环境支持增删段落和任意混排，由 LyX 原生导入。没有结构标记且段落数改变的混合目标按普通正文应用，并明确反馈，不猜定理边界。保留当前文档/进程检查、禁止原生语法注入及一次撤销。
2. 源码：以完整选区结构判定 ERT 整块、内部及正文混排，不能仅以选区末端光标布局判定。统一识别 LaTeX 控制序列及混排的 latex/tex 代码围栏，保留数学、引用和文档已有宏的排版路径。提供带定理/证明边界与 ERT 命令的 AI 请求表示，减少模型丢失结构。
3. 模板：内置模板始终来自程序预设。首次编辑自动创建用户自定义模板，后续编辑只保存该自定义项；切换、保存、关闭和界面语言切换不得改写内置模板。旧版本已修改的预设内容迁移为自定义项并保留当前选择，迁移幂等。
4. 界面：用柔和紫色提示词面板、清晰标题和说明突出任务入口，保留白色主背景、深色系统下的可读性及小屏幕滚动。
5. 验证：快速回归覆盖模板分叉/迁移/重开、混合布局及 ERT 判定、原生语法与危险 TeX 拒绝；隐藏 Windows 桌面实测多个 Theorem/Proof/Standard/ERT、LaTeX 导出和 PDF 编译、一次撤销。再检验真实预览、小屏幕、打包版启动/IPC/安装卸载、ZIP 完整性。使用临时数据和本机 mock，不调用用户 AI 账户，不改动已安装程序。
6. 交付：更新双语无版本 README、截图、使用和覆盖升级教程，构建独立的 Windows ZIP、SHA-256 及本次验证报告。
