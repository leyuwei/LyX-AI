# LyX AI 0.4.1

- 主界面和弹窗使用一致的白色背景，移除区域灰底，防止深色系统背景导致正文区域变黑、文字无法辨认。
- 问询原文、前文、后文改为三个带字符数的按钮，按需打开编辑弹窗；保存提交修改，取消保留原内容。自动正文上下文仍正常拉取，弹窗尺寸记忆并适配屏幕。编辑期间如收到 LyX 新内容，旧弹窗不会覆盖它。
- 历史默认单独显示 AI 回复，按轮次查看首问与追问；用户问询、思考摘要、完整对话分别展示。失败、取消和中断显示状态及已收到的部分回复，无回复时明确提示。
- 已有设置与历史直接兼容，无需迁移；保留预览窗口复用、当前选区/光标写回、原生公式、定理及 LaTeX 源码支持。
- 修复 Windows 剪贴板格式缓存的偶发时序问题：粘贴前同步目标 LyX 进程的监听器，避免快速写回时公式或 LaTeX 结构退化为普通文本；同步失败时不执行粘贴。

Windows 验证结果见[测试说明](TESTING.zh-CN.md)。升级请退出 LyX 和助手，完整解压新版包后运行 `Install.cmd`，设置与历史保留；详见[覆盖升级教程](UPGRADE.zh-CN.md)。本次没有在 macOS 实机打包验收。
