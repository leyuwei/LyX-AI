# 0.4.0 实施与验收计划

1. 设置：统一捕获界面语言、回复语言、模板选择及编辑、当前模型、自动上下文开关与范围、窗口位置大小、分栏与标签状态；修改后合并保存，关闭时同步刷新。兼容现有配置，增加前后各 1200 字符。模型配置继续通过“保存/取消”明确提交。
2. 布局：主窗口按屏幕可用区域初始化并恢复位置；小窗口使用可滚动的输入/输出面板、可滚动标签和分行工具栏。配置对话框随宽度切换布局。底部状态固定单行、省略溢出，悬停显示完整内容。
3. 预览：主窗口首次显示前准备浏览器控件，切换标签复用相同控件与页面；相同内容不重新加载。验证窗口句柄、位置、输入内容、会话与页面滚动位置不会因标签切换重置。
4. 历史：使用 Python 标准库 SQLite 独立保存每次问询及追问、回答、思考摘要、修改稿、模型名称和完成/失败状态；按需检索和载入，不把密钥、认证头或 LyX 原生回写凭据存入历史。异常中断保留已开始的请求；失败保留收到的部分内容。提供单条删除。
5. 结构回写：普通修改稿保留 Theorem/Lemma 等当前布局；包含 LaTeX 环境、章节或文本格式时使用 LyX 原生导入，并匹配当前文档的定理模块。ERT 整块、内部文字和光标插入保留源码；源码内部的剪贴板可能变为 Standard，必须用实时布局识别。验证 HTML 定理标签、LaTeX 导出、PDF 编译和一次撤销。
6. 验收：快速回归使用离屏 Qt 和本机 mock；增加关闭重开设置、模板切换、成功/失败/追问历史、搜索删除与无认证信息检查。独立 GUI 检查覆盖中英文小屏幕、长状态和真实浏览器首次/反复切换；保留真实 LyX 公式回写及一次撤销检查。打包后重复预览、IPC 与隔离安装检查，核对 ZIP、校验值和文档。

问答历史为用户主动要求的本地持久化内容，默认保存在配置目录的 `history.sqlite3`，不自动上传；文档同步说明备份、删除和升级保留方式。README 继续不写版本号。
