# 0.3 升级实施方案

1. **LyX 桥接**：使用 LyX 默认已启用的 Windows named pipes；菜单先复制结构化选区，助手在后台查询当前文件并导出当前内存文档到临时 `.lyx`。从结构化正文提取目标附近上下文，跳过 Note、Foot 等对象。歧义或导出失败明确显示原因，保留手动补充入口。
2. **安全写回**：保留选区原生片段和文档身份。单独设置“待替换正文”编辑页；AI 使用 `[REVISED]` 标记分离修改和解释。点击应用时再次查询当前文档、复制当前选区，与原始结构核对，匹配才粘贴原生 LyX 片段。公式写成 Formula inset，支持 `$…$`、`\(…\)`、`$$…$$`、`\[…\]`；单行独立公式保持 Displayed。含 Note/Foot/引用等无法无损重建的目标拒绝覆盖，防止误删结构。LyX 可撤销。
3. **阅读与性能**：离线 Markdown + KaTeX，HTML 输入禁用、禁止远程资源和脚本导航；预览仅在标签激活和停止输入后更新，流式源码仍批量刷新。独立进程渲染器仅打开预览时加载。
4. **视觉**：绘制可缩放 SVG 图标及 Windows ICO，统一窗口/任务栏/可执行文件图标；青蓝配色、明确焦点/悬停状态、圆角按钮和自绘下拉箭头，保留键盘及高对比可读性。
5. **菜单语言**：自定义菜单使用 gettext 消息 ID；用户目录生成 LyX 翻译覆盖层，保留原有翻译并增加助手条目，通过 `LYX_LOCALEDIR` 供 LyX 自动按界面语言选择。支持中英等常见语言，未知语言回退英文；不改 Program Files。提供立即生效的启动入口及恢复配置的卸载。
6. **测试与交付**：默认快速离屏单元/协议测试；额外一次隔离 LyX 离屏通信、快照、原生公式粘贴与撤销验收；一次离线预览渲染检查。更新覆盖升级、保留模型设置、语言生效、公式语法及故障恢复文档，重建 Windows 包。

## 边界
不自行改写用户磁盘上的原文，不自动执行 AI 返回的指令；只在点击应用后通过 LyX 自己的 paste 修改。目标选区变动、文档变动、结构不安全时拒绝写回。支持正文中的完整公式对象；不支持直接编辑公式 inset 内的一部分，也不把 Markdown 表格/复杂排版自动重建成 LyX 表格。
