# 覆盖升级安装

1. 保存文档，退出 **LyX 和 LyX AI**。
2. 将新版 `LyXAI-Windows.zip` **完整解压到一个新文件夹**。不要在压缩包内运行，不要只取 EXE。
3. 双击新版 `Install.cmd`，将整个程序覆盖安装到 `%LOCALAPPDATA%\LyXAI`。通常无需管理员权限。
4. 从 Windows 开始菜单打开 **LyX AI - Start LyX**，让新菜单翻译立即生效。
5. 框选正文，右键选择 **AI 写作助手… / AI Writing Assistant…**。等待“正文已读取”；“问询原文 / 前文 / 后文”按钮显示字符数，点击可在弹窗查看、修改并保存。

**升级不需要先卸载。** 模型、API Key、超时、模板和界面语言保留在 `%APPDATA%\LyXAI\config.json`，安装脚本不覆盖它。启动后，旧版本已改写的内置提示词会迁移为自定义模板，原始内置内容恢复，当前选择保留。本地历史保存在同目录的 `history.sqlite3`，安装脚本同样保留；备份整个目录可同时备份设置与历史。建议升级前复制整个 `%APPDATA%\LyXAI` 作为个人备份；备份包含加密凭据，请自行保管。旧菜单标记块会更新，不会重复添加。

新版提示词配置使用新的配置格式，内置项只保存标识。首次保存旧格式时会在同目录生成 `config.before-template-migration.json`，保留升级前的加密配置。回退旧程序时，应退出程序后将升级前备份恢复为 `config.json`；旧程序不能直接读取新版配置。模型接口与历史数据库格式不变。

全局底栏的“应用到 LyX 当前位置”使用最新选区或光标：有选区则替换，无选区则插入。等待 AI 时可调整位置或编辑同一文档；应用后可继续选择其他位置再次应用。底部 © github/leyuwei 可打开插件主页。

程序目录中的 `_internal`、QtWebEngineProcess 和字体等依赖必须一起保留。新版带离线公式浏览器，安装包比旧版大；主窗口显示前准备浏览器并复用，点击阅读预览不再重建窗口。不要只复制新版 EXE 到旧目录，也不要把压缩包内容直接覆盖源码目录。

## 本次升级内容

- 修复 IEEEtran 与 AMS 定理模块冲突导致的多布局写回失败。转换先在临时目录预检，成功后一次原生粘贴，不再调用 LyX 的 `paste latex` 转换链。
- 问询范围纳入 Label、Float、Caption、Table、Box/Minibox 及其他 inset 内容和源码；仅排除 Note、Footnote、边注内容。
- 保留原生图片资源，修正剪贴板来源目录引起的相对路径变化；表格形状不变时保留行列设置、边框、宽度，以及盒子、浮动项和对应段落间距。
- 内置提示词增加双语结构保护规则；现有自定义模板不改写，实际请求仍追加保护要求。已有模型设置、历史和界面偏好继续兼容，无需重新填写密钥。
- 图片和复杂对象以 `\lyxaiobject{…}` 标记保留。请让 AI 原样保留标记和相对位置；标签或资源缺失时会在写回前提示，原文保持不变。合并单元格等复杂对象内部暂作只读参考。

本次升级请完整覆盖程序目录，不能只更新 EXE：新增的转换与结构处理代码和原有 Qt/公式资源需一起安装。转换使用已安装 LyX 自带的 tex2lyx，无需另装转换器，也不会修改 `C:\Program Files\LyX 2.5`。

## 语言生效方式

默认 `auto` 使用 LyX 的 gettext 翻译机制，跟随 **LyX 界面语言**。安装在用户目录生成 `lyxai-locale`，保留原有翻译并增加助手菜单，同时设置用户环境变量 `LYX_LOCALEDIR`。

新开始菜单入口会在启动进程中设置语言目录，可以立即生效。如果继续使用旧桌面快捷方式，且翻译尚未生效，请注销 Windows 后重新登录一次，刷新旧启动进程的环境。改变 LyX 界面语言后，按 LyX 提示重启即可。

支持中文、英语、德语、法语、西班牙语、意大利语、日语、韩语、葡萄牙语、俄语；其他语言的新增菜单回退英文。助手右上角的语言选择只控制助手窗口。

用户环境变量也会影响其他版本的 LyX。并用多个大版本时，可在各自启动脚本中指定相应的 `LYX_LOCALEDIR`，或使用固定标签安装：

```powershell
.\Install.ps1 -MenuLanguage zh
.\Install.ps1 -MenuLanguage en
```

若此前已安装 auto，改为固定标签不会自动删除已有覆盖层；要恢复原环境，可以先卸载菜单，再以固定语言安装，模型配置保留。卸载会恢复安装前的语言变量，除非该变量后来被其他程序修改。

## 无 API 的短验收

1. 打开 `examples/context-demo.lyx` 的副本，框选中间 Target passage，右键启动助手。
2. 三个正文按钮应显示字符数。点击前文 / 后文，自动填入的内容应没有 `DO NOT SEND` 备注、脚注文字；试改后取消应保持不变，保存后重新打开应保留修改。未发送的内容不保证在退出后恢复。
3. 在“待替换正文”输入 `New text $x_i^2$. \[y=\frac{a}{b}\]`，先预览，再点击全局底栏的“应用到 LyX 当前位置”。切换回答/预览等标签后按钮也应始终可见。
4. LyX 中应出现原生行内公式和单行 Displayed 公式。也可用 `examples/multiline-formula.tex` 的 align 检查多行对齐、编号和标签。一次 Ctrl+Z 应恢复原文。
5. 更换选区后应用，应替换新选区；单击正文放置光标后应用，应在该位置插入，保留周围文字。两种操作均应可一次 Ctrl+Z 撤销。编辑同一文档后仍能应用；切换到其他文档时应拒绝写入。
6. 在助手右上角选择 English，关闭助手后再次从 LyX 打开，应仍是英文。可切回简体中文，选择会立即保存。点击窗口底部 © github/leyuwei，应由默认浏览器打开 https://github.com/leyuwei/LyX-AI。

7. 将回复语言、模板、上下文范围设为自定义值（含 1200），调整窗口大小，关闭重开后应恢复。长状态只占一行，悬停可看全文。
8. 切换阅读预览数次，窗口不应重新打开。小窗口下可滚动输入和输出，底部应用和历史按钮可达。
9. 完成一次问询和追问后关闭重开，从“问答历史…”检索；默认“AI 回复”只展示对应轮次的回复，切换轮次能查看其他答案，用户问题和思考摘要在各自标签。原有记录也可查看、载入后继续追问。历史需要一条实际或本机 mock 请求才能产生。
10. 使用 `examples/regions-demo.lyx` 的副本验证 Theorem、Lemma 与源码回写，检查排版并一次撤销。

11. 使用 `examples/mixed-layouts-demo.lyx` 的副本，选择两个 Theorem、Proof 和中间正文一起问询，修改稿保留相应 LaTeX 环境及源码命令，应用后应仍有两处定理和证明，并可一次撤销。纯文本段落数改变时会提示按正文布局应用。
12. 在紫色提示词区选择内置项并编辑，列表应转为用户自定义；继续编辑不应不断新增项。切回内置项内容应保持原样，重开后自定义修改仍在。
13. 打开 `examples/objects-demo.lyx` 的副本，图片资源为同目录的 `sample.png`。预览发送内容应包括图表标题、表格文字、盒内正文、标签及保留标记；保留标记后修改这些文字并应用，图片仍应可见，边框、宽度和间距保留。一次撤销恢复全部原文。
14. 在 IEEEtran 文档中应用包含 lemma/proof 和多行公式的修改稿，应产生原生布局及数学对象；转换失败应在助手底部显示原因，不能弹出 LyX 的 Cannot convert file 对话框。内置模板应出现完整的结构保护要求。

真实 API 账户和右键显示仍需这次短验收。自动测试已覆盖 LyX Server、结构化剪贴板、原生公式粘贴和撤销，不需要重复运行鼠标与截图自动化。

## 回退与恢复

退出两个程序，运行 `Uninstall.ps1`，恢复原菜单和语言环境并移除新开始菜单入口。然后可重新完整安装旧版程序。模型配置默认保留；不同版本间兼容性仍建议用升级前备份恢复。

程序、设置及惰性的翻译缓存默认不删除。确认卸载后可按需手动清理。完整路径、源码安装和故障排查见[安装教程](INSTALL.zh-CN.md)。

## 模块兼容性补充

同一版本安装包已补充通用模块规则和验证。请重新下载完整包并按上文覆盖安装；设置和历史不变。兼容性按文档类/模块声明计算，覆盖类提供/排除模块、双向互斥、依赖顺序、默认与用户移除项。无效组合在写回前显示具体原因，不修改原文档模块。范围和限制见[模块兼容性说明](MODULE-COMPATIBILITY.zh-CN.md)。
