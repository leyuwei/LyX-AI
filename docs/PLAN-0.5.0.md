# 0.5.0 实施与验收计划

## 已复现的根因

- 使用用户提供的完整 lemma/proof，在 IEEEtran 与 theorems-ams-bytype、theorems-ams-extended-bytype 组合下运行与截图一致的 tex2lyx 命令，退出码为 1：IEEEtran 提供的定理模块与显式 AMS 模块冲突。
- 原流程先交给 LyX 的 paste latex 执行转换，无法在修改前处理转换失败，导致模态错误对话框。
- 正文过滤白名单排除了图、表、盒子和标签，结构化请求只覆盖了定理、公式、引用和 ERT。

## 实施顺序

1. 统一结构提取：仅排除 Note、Foot、Marginal 等注释对象；遍历 Float、Caption、Tabular、Box/Minibox、Flex 和其他容器。保留公式、标签、引用、源码及有意义的空白，避免对象参数和表格 XML 泄露为正文。
2. 结构化请求：提供可往返的 LaTeX 环境、标签、表格、标题、盒子及源码。对图片等已有资源和无法可靠重建的对象使用原生保留标记，同时提供可读内容，防止资源路径或复杂原生参数丢失。
3. 写回预检：在临时目录运行 tex2lyx，处理类内置模块冲突及环境别名，成功后发布原生 LyX 剪贴板并只执行一次粘贴。转换失败不得操作选区或触发 LyX 的模态导入错误。保留当前选区/光标、文档来源检查和一次撤销。
4. 结构保留：标签、图片资源、表格和间距不应被静默丢弃；处理原生参数、嵌套容器及选区内部的编辑。所有内置模板添加双语结构保护要求，自定义模板仍在实际请求中获得保护规则。
5. 测试：快速回归验证过滤、结构序列化、资源保留和失败前无修改；真实 tex2lyx 覆盖 article/IEEEtran、模块组合、用户完整复现文本；真实 LyX 验证布局、标签、Float、Caption、Table、Box、Spacing、公式、导出及一次撤销。使用隔离用户目录、临时文档和隐藏桌面，不调用付费 API。
6. 交付：更新版本、双语 README 的能力说明、使用/覆盖安装教程及测试记录；重新构建 Windows ZIP，检查打包程序、归档完整性并提供 SHA-256。

核查发现原实现遗漏类级排除、模块间双向互斥、依赖重排、默认/移除项，并仍使用定理类名白名单。现统一从已安装定义解析这些规则；新增临时模块图快速测试和 18 组真实转换、4 组互斥拒绝。完成后复测原有结构写回，重新构建同版本 Windows 包并更新校验值。
